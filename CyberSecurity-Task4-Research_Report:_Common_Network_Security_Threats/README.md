# Network Security Threats Report

## Project Overview

This repository contains a research report on common network security threats, developed as part of the **Oasis Infobyte Cyber Security Internship (Task 4)**. The report examines four widely encountered categories of network-based attacks, explains how each one works at a technical level, and links each to a real, documented security incident. It is intended as a concise, recruiter-facing reference that demonstrates applied research and technical writing skills in cyber security.

## Objective

The objective of this task was to research, analyze, and document major network security threats in a clear, structured, and professional format, covering:

- The mechanics of each threat
- Real-world case studies
- Organizational and individual impact
- Practical mitigation strategies

## Features Covered

- In-depth explanation of four major network security threats
- Step-by-step breakdown of how each attack is carried out
- Real-world case studies with documented outcomes
- Discussion of financial, operational, and reputational impact
- Three detailed, practical mitigation strategies per threat
- A comparison table summarizing all threats side by side
- APA-style references from credible cyber security sources

## Topics Researched

- Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS) attacks
- Man-in-the-Middle (MITM) attacks
- IP Spoofing
- DNS Poisoning / DNS Spoofing
- Network defense and mitigation strategies (DNSSEC, RPKI, HSTS, certificate pinning, ingress/egress filtering, traffic scrubbing)
